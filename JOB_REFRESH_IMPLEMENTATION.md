# Job Refresh Feature - Complete Implementation 🔄\n\n## Overview\nThe Job Refresh feature allows employers to \"refresh\" their job postings, moving them back to the top of search results by updating the posting timestamp. This is a common feature in job portals like LinkedIn, Naukri, and Indeed.\n\n## 🎯 Features Implemented\n\n### Frontend Components\n- **JobRefreshButton.tsx** - Individual job refresh with smart states\n- **BulkJobRefresh.tsx** - Multi-select job refresh functionality  \n- **RefreshStatusIndicator.tsx** - Visual refresh status on job cards\n- **useJobRefresh.ts** - Custom hook with business logic\n- **jobRefreshAPI.ts** - API service layer\n\n### Backend Implementation\n- **Job Model Updates** - Added refresh fields to database\n- **API Endpoints** - Complete REST API for refresh functionality\n- **JobRefreshService** - Business logic and rules engine\n- **Database Migration** - Script to update existing database\n\n## 🏗️ Database Schema Changes\n\n```sql\n-- New fields added to jobs table\nALTER TABLE jobs ADD COLUMN refreshCount INTEGER DEFAULT 0;\nALTER TABLE jobs ADD COLUMN lastRefreshedAt TIMESTAMP NULL;\nALTER TABLE jobs ADD COLUMN originalPostedAt TIMESTAMP NULL;\n\n-- Indexes for performance\nCREATE INDEX idx_jobs_refresh_count ON jobs(refreshCount);\nCREATE INDEX idx_jobs_last_refreshed ON jobs(lastRefreshedAt);\n```\n\n## 📡 API Endpoints\n\n### 1. Refresh Single Job\n```http\nPOST /api/jobs/:id/refresh\nContent-Type: application/json\n\n{\n  \"userPlan\": \"free\" // \"free\" | \"pro\" | \"enterprise\"\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Job refreshed successfully\",\n  \"job\": {\n    \"id\": \"job-uuid\",\n    \"refreshCount\": 1,\n    \"lastRefreshedAt\": \"2024-01-20T10:00:00Z\",\n    \"postedAt\": \"2024-01-20T10:00:00Z\",\n    \"originalPostedAt\": \"2024-01-01T10:00:00Z\"\n  }\n}\n```\n\n### 2. Bulk Refresh Jobs\n```http\nPOST /api/jobs/bulk-refresh\nContent-Type: application/json\n\n{\n  \"jobIds\": [\"job1-uuid\", \"job2-uuid\"],\n  \"userPlan\": \"free\"\n}\n```\n\n### 3. Get Refresh Status\n```http\nGET /api/jobs/:id/refresh-status?userPlan=free\n```\n\n### 4. Get Refresh Analytics\n```http\nGET /api/jobs/refresh/analytics?employerEmail=user@example.com&userPlan=free\n```\n\n## 🎯 Business Rules\n\n| Plan | Max Refreshes | Cooldown Period | Cost |\n|------|---------------|-----------------|------|\n| **Free** | 3 per job | 7 days | Free |\n| **Pro** | 10 per job | 1 day | Premium |\n| **Enterprise** | Unlimited | No cooldown | Enterprise |\n\n## 🚀 Setup Instructions\n\n### Backend Setup\n\n1. **Navigate to backend directory:**\n   ```bash\n   cd zyncjobs-backend\n   ```\n\n2. **Run the setup script:**\n   ```bash\n   node scripts/setupJobRefresh.js\n   ```\n\n3. **Or run migration manually:**\n   ```bash\n   node scripts/migrateJobRefresh.js\n   ```\n\n4. **Start the server:**\n   ```bash\n   npm start\n   ```\n\n### Frontend Setup\n\nThe frontend components are already integrated into the JobManagementPage.
